# REQ-0002 给对拍协议补两道独立工序：独立裁决与修复复核

## 问题与目标

裁决与修复常落回主代理（实现者 = 裁决者 = 修复者），自审偏弱。实测依据：一轮独立裁决抓出主代理裁决 3 处双标 / 尺度不一（`ok` 三态案、双守卫案、缩进案）；用户要求把「独立复核 diff」固化进技能。目标：`shy-code-review` 增加可选第 6 步——**独立裁决**（防锚定重裁）与**修复复核**（只读核 fix diff），模型与实现者、评审三方互异。

## 触发与分支

`shy-code-review` 流程内两类时机：孤证裁决出自实现者 / 主代理之手 → 独立裁决；修复批落地后 → 修复复核。用户明说跳过则不跑。

## 行为与步骤

1. **独立裁决**：1 个裁决子代理，只见各跑原始报告 + 规格来源（**不见主代理裁决**，防锚定），全量重裁并自行归并；与主代理裁决逐条对照，分歧摆开呈现并注明采用哪方及理由。
2. **修复复核**：1 个只读子代理核 fix diff，逐 finding 判四档（正确修复 / 不完整 / 未修 / 不修是对的）+ 新问题扫描（重点核对被重构处的行为语义）。
3. 模型选择：避开实现者与评审三方（先查模型目录、不猜 ID，同第 4 步规则）。

## 脚本与资源

- `~/.agents/skills/shy-code-review/SKILL.md` 新增「第 6 步 · 独立裁决与修复复核」节。

## 降级与边界

- 两道均只读；修不修由用户拍板。
- 独立裁决子代理失败 → 同模型重试一次，再失败保留主代理裁决并标注「未经独立裁决」。
