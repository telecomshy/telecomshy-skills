# 普通 Markdown 笔记最佳实践（智识沉淀专用）

本参考文件用于指导生成**普通 Markdown**（非 Obsidian）格式的笔记。仅当保存格式为普通 Markdown 时查阅。
目标：在任何 Markdown 阅读器（VSCode、Typora、GitHub、语雀等）中都能正确显示、链接可点击。
本文件只讲普通 Markdown 的**语法与格式**；写作层面的规则（事实与推断、易变事实日期、信息不完整降级、冲突标注、通俗解释取舍、文风）以 SKILL.md Step 6 为准，不在此重复。

---

## 一、与 Obsidian 格式的核心差异

| 能力 | Obsidian | 普通 Markdown |
| --- | --- | --- |
| 笔记间链接 | `[[笔记名]]` 双链 | `[显示文字](笔记名.md)` 标准链接 |
| 反向链接 | 原生自动生成 | **无**，需手工补（见第三节） |
| 元数据 | YAML frontmatter | 不强制，建议正文开头写标题与日期 |
| Callouts | `> [!warning]` 有样式 | 会退化为普通引用，改用加粗前缀引用块 |
| 高亮 | `==高亮==` | 不通用，改用加粗 |
| 块 ID / 嵌入 | `^块id`、`![[...]]` | **不支持**，改用普通链接 |
| 标签 | `#标签` 可检索 | 无索引能力，仅作普通文本 |

> 一句话原则：**只写标准 Markdown（CommonMark）子集**，不写任何 Obsidian 专属语法。

---

## 二、笔记结构与排版

1. **开头写标题与日期**（无 frontmatter 时的替代方案）：

   ```markdown
   # 示例笔记标题

   > 创建：2026-09-09　来源：对话总结
   ```

   - 日期便于日后判断内容时效，与「易变事实加日期戳」的规则配合使用。
   - 如保存目录本身被 Git 或其它工具管理，也可改用其元数据约定。

2. **正文排版**：
   - 标题层级用 `#`，最多到 `####`（更深的层级在多数渲染器中不可靠）。
   - 段落之间留空行。
   - 强调用 `**加粗**`、`*斜体*`（`==高亮==` 在多数渲染器不生效，改用加粗）。
   - 列表用 `- ` / `1. `，代码用行内 `` ` `` 与围栏 ``` ```。
   - 表格用竖线，表头下方必须有分隔行。

3. **替代 Callout 的写法**：用加粗前缀的引用块，兼容性最好：

   ```markdown
   > **注意**：变更前必须备份，避免回滚失败。
   ```

   - 常见前缀：**注意**、**提示**、**踩坑**、**结论**、**通俗理解**（承载白话解释、类比）。

---

## 三、笔记间链接与反向链接

1. **链接写法**：用标准 Markdown 相对链接，带 `.md` 扩展名。

   ```markdown
   相关经验见 [示例笔记标题](示例笔记标题.md)。
   ```

   - 同分类下直接写文件名即可；跨分类用 `../分类名/笔记名.md`。
   - 标题含空格或特殊字符时，用 `%20` 等百分号编码，或改用 `<...>` 包裹：
     `[显示文字](<含 空格的标题.md>)`。
   - 用标准链接；`[[笔记名]]` 在普通 Markdown 阅读器里只是纯文本、点不动。

2. **反向链接需手工补**（这是与 Obsidian 最大的差异）：在目标笔记末尾的「相关笔记」章节补一行链接；无该章节则新建。补链规则（只补本次实际引用到的关联、仅限 `AI笔记` 目录内的笔记、不动用户自建笔记）见 SKILL.md Step 6「关联」。

3. **建议的「相关笔记」章节**：

   ```markdown
   ## 相关笔记

   - [示例笔记标题](示例笔记标题.md)
   - [另一篇笔记](../其它分类/另一篇笔记.md)
   ```

---

## 四、索引文件

- 分类索引文件同样命名为 `00-分类索引.md`，由脚本自动维护。
- 索引里的笔记链接由脚本按格式生成（普通 Markdown 下为 `[标题](标题.md)`），保持脚本产出即可。
- 「已收录疑问」章节格式：`- 疑问 → [笔记标题](笔记标题.md)`。

---

## 五、检索与健康检查

- `search-notes` 按关键词检索正文，对两种格式完全一致。
- `lint-notes` 同时识别 `[[双链]]` 与 `[文字](笔记.md)` 两种链接，可查出断链、索引遗漏等问题；图片、外链、纯锚点会自动跳过，不会误报。

---

> 与 Obsidian 格式的取舍：普通 Markdown 牺牲了反链自动化与丰富语法，换来跨工具通用性。若你后来改用 Obsidian，只需通过「修改智识沉淀设置」切换格式，笔记正文内容无需重写（仅链接写法与索引会按新格式生成）。
