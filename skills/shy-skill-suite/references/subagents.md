# 复审外派子 agent

复审里"**跑**""**评**""**分析**"外派给子 agent；主 agent 只保留"写""问用户""综合决策"。两个动机：**独立性**（谁写的谁不评分）与**干净上下文**（跑技能时不带本会话历史）。

## 派发还是内联

**评审必须独立于作者**：跑 / 评 / 分析一律派**独立子代理**（作者不参与）。客户端支持子 agent（opencode 的 Task / Claude Code 的 Task / TeleAgent 的子任务）→ **派发**；不支持 → **内联**执行，但必须在报告注明"**未隔离**（独立性打折）"并**下调结论置信度**——**自审不是独立评审**。

**独立性只加在"评审"这一环，不加到"修复"上**：修复由主代理做（要全貌与决策，见下「不该外派」），修完只跑 **Gate**（确定性脚本，谁跑结果都一样）、**不派子代理复验、不自动重开评审**——否则重新引入循环。**确定性的东西不需要独立，判断才需要。**

派发时**窄 brief、短返回**：只给该角色所需的最小输入，只收结论，不把长轨迹带回主上下文。

**触发检测**：若客户端能观测子 agent 的工具调用，由主 agent 判定 `used_skill`；否则由子 agent 自报（较弱，需标注）。

## 角色

### executor（服务 Step 1 触发、Step 2 有/无技能对照）

- **输入**：一条 prompt；技能路径（with）或无技能（baseline）；输出目录。
- **任务**：在**干净上下文**里只跑这一条，以用户视角完成；产出文件；记录 tokens / 耗时。
- **输出**：`outputs/`、`timing.json`、`used_skill: true|false`。
- **禁止**：不重试、不评判、不参考"期望结果"。
- **关键**：baseline **必须真的没有该技能**；with-run **不要把期望答案给它**（否则等于作弊）。

### grader（服务 Step 2 / 3）

- **输入**：一个 run 的产出；断言列表。
- **任务**：逐条 PASS / FAIL 并**引用证据**（原文 / 文件名 / 计数）→ `grading.json`（`pass_rate`）。
- **额外两职责**（让**"测不出东西的测试"**暴露出来）：
  - **抽取并核验隐式主张**：断言之外，从产出里抽出可核验的**事实 / 过程 / 质量**主张（如"用了 2023 年数据""脚本已加 `--force`"），逐条给通过 / 不通过 + 证据 → `grading.json` 的 `claims[]`。预定义断言漏掉的事实错误靠它兜。
  - **兼评评测集本身** → `grading.json` 的 `eval_feedback[]`：**弱断言**（只查文件名不查内容）、**遗漏结果**（该测的重要结果没测）、**不可验证断言**（指不出证据）。一条"通过了但测不出东西"的断言，比没有更糟。
- **输出**：`grading.json`（`pass_rate` + `assertions[]` + `claims[]` + `eval_feedback[]`）。
- **禁止**：不改产出；**不知道哪份是 `with_skill`、哪份是 `baseline`**（盲）；不给"benefit of the doubt"——证据不足即 FAIL。

### spec-reviewer（服务 Step 3 Spec 轴）

- **输入**：技能文件集；各 REQ 的 `## 验收标准`（不变量集，限 `in-progress` / `done`）与 `（未定）`项；已有证据。**不喂** 问题与目标 / 行为与步骤 / 范围外 / 备注（冻结历史）。
- **任务**：逐条验收标准 → 通过 / 部分 / 未实现（**引用验收标准那一行**）；报**范围蔓延**（不变量 / 技能文件没要求的行为）；报**文档-实现不一致**（基准为技能文件：`description` / 路由 ↔ 分支、范围声明 ↔ 实现、脚本接口 ↔ 文件）。
- **输出**：分轴 findings（每行：验收标准行或技能文件行 + 判定 + 证据）。
- **禁止**：不改技能；不做质量评价（那是标准轴）；无 REQ 就报 `no spec available`；**引用历史散文的候选直接丢弃**。

### analyzer（可选，服务 Step 8）

- **输入**：`benchmark.json`、各 `grading.json`。
- **任务**：失败聚类、flaky（`pass_rate_std > 0.3`）、跨轮回归、成本离群、触发 TPR / FPR；外加**断言模式分析**——**恒过**（with_skill 与 baseline 都过 → 该断言测不出东西，建议删或换）、**恒败**（两边都败 → 查断言写错还是题太难）、**有无技能反转**（baseline 反超）。
- **输出**：3–5 条结论，并**落盘 `<iteration>/analyzer_notes.json`**（`{"notes": ["...", "..."]}`）——`aggregate_benchmark.py` 会并入 `benchmark.json.notes`，报告会渲染；不落盘就只在对话里，等于没留证据。
- **禁止**：不重新跑评测。

### comparator（可选，主观质量）

**何时**：比较**两个版本**，且技能产出含主观质量（文风 / 结构 / 设计 / 可读性 / 忠实度）。纯行为型技能不需要。

- **输入**：同一 prompt 的两版产出（**匿名化、随机标 A/B**）。
- **任务**：按 rubric 打分（结构 / 可读性 / 忠实度 / 有用性）+ 偏好 + 置信度。
- **怎么做**：**两个顺序都跑**（先 A 后 B、先 B 后 A）以抵消位置偏好；只给产出，不给"哪版是新版 / 哪版更好"的任何暗示。
- **输出**：偏好 + rubric 分 + 理由；**与断言结果并列报告、不合并**（两版可能都过断言，差别在主观）。
- **禁止**：不被告知哪份是哪版；不重新跑评测。
- **注意**：LLM 裁判有位置 / 冗长 / 自我偏好，盲测只**缓解**不消除——结果是**信号**，不是证据。

## 与 `agent_runner.py` 的关系

- **脚本版**（`agent_runner.py`）：无头、可脚本化，适合 `--runner opencode|teleagent|cmd`。
- **子 agent 版**：agent 原生、**真上下文隔离**，无需外部 CLI。
- 二者互补：**能派发时优先子 agent**；无头 / 批量时用脚本。

## 副作用禁令

子 agent 是**后台执行者**，不得产生用户可见副作用：

- **不弹浏览器**：跑 `render_report.py` 一律加 `--no-open`（或设 `SHY_NO_OPEN=1`）。报告只在复审 Step 8 由主 agent 打开一次。
- **不写仓库**：测试产物写临时目录；不得改 `skills/` / `docs/` / 用户配置。**台账由主 agent 结清、子代理只发现**（禁写不变）：子代理只返回台账候选，**结清归主 agent**——主 agent 可改技能文件与 `docs/<skill>/cleanup.md`（台账项常需改技能文件，如去重），**改完过 Gate**。
- **不装东西**：不安装依赖、不改本机配置（命令模板只交付、不代装）。

派发 brief 里要写明这条；违反的轨迹按"复审自身反模式"记。

## 不该外派

- 逼问（要用户交互）、落需求（要整段对话）、改进意见综合与回写 REQ（要全貌与决策）。
- 确定性工作（`track_requirements.py` / `validate_skill.py` / `aggregate_benchmark.py`）已由脚本完成，不必外派。
